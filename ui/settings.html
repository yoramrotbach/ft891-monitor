Connection
Serial port

The radio's USB jack shows up as two ports (Silicon Labs CP210x). Pick the Enhanced one (Windows Device Manager names it "Enhanced COM Port"). The Standard port is for PTT and keying.

Baud rate must match menu 05-06 CAT RATE (factory default 4800). Keep RTS/CTS on while menu 05-08 CAT RTS is ENABLE (the default). DTR is always held low.

rigctld

Example: rigctld -m 1036 -r COM3 -s 38400. Most indicators and controls work; NAR, IPO, FST and the meter selection need a direct connection.

Control

Tuning, mode, band, VFO A/B, split, lock, IPO/ATT/NAR/NB/DNR/FST and power. The app can never transmit: transmit, tune, VOX, keying, menu and memory-write commands are blocked in code. Changes are refused while the radio is transmitting, and tuning is refused while its dial LOCK is on.

Display

The radio doesn't report which A/B/C key row is showing, so pick the one you use. Labels for toggles (DNR, NB, ATT, IPO, NAR) are clickable.

Connection changes apply when you click Done.
